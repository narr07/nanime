Each example composes several parts of `nanime` into one sequence, the kind
of thing you would ship rather than a single API in isolation. Per-API
previews live on the [composable pages](/composables/introduction).

::u-page-grid
  :::u-page-card{to="/examples/timeline-storyboard" icon="i-ph-list-numbers" title="Timeline storyboard" variant="soft"}
  #description
  Several tracks, each its own timeline, synced into one master with scrub controls.
  :::

  :::u-page-card{to="/examples/drag-to-bin" icon="i-ph-trash" title="Drag to bin" variant="soft"}
  #description
  Drag a card onto the bin, and the list closes the gap behind it.
  :::

  :::u-page-card{to="/examples/loading-sequence" icon="i-ph-spinner-gap" title="Loading sequence" variant="soft"}
  #description
  Idle to loading to success, with a scrambling status line between states.
  :::

  :::u-page-card{to="/examples/text-scatter" icon="i-ph-magnet" title="Text magnet" variant="soft"}
  #description
  Magnetic proximity effect flipping between repelling and attracting characters every 5 seconds.
  :::

  :::u-page-card{to="/examples/scroll-card-stack" icon="i-ph-cards" title="Scroll card stack" variant="soft"}
  #description
  A deck of cards that fans out as you scroll, in a layout that switches by orientation.
  :::

  :::u-page-card{to="/examples/svg-walker" icon="i-ph-footprints" title="SVG walker" variant="soft"}
  #description
  A small SVG character that walks a hand-drawn path, back and forth.
  :::

  :::u-page-card{to="/examples/swipe-cards" icon="i-ph-cards-three" title="Swipe cards" variant="soft"}
  #description
  Drag a card far enough and it flies off, the next one takes its place.
  :::

  :::u-page-card{to="/examples/clock-transport" icon="i-ph-clock-countdown" title="Clock transport controls" variant="soft"}
  #description
  A live clock driven by one timeline, with play, pause, reverse and speed controls.
  :::
::
